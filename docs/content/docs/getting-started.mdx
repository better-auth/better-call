---
title: Getting started
description: Define a typed function and call it.
---

```ts
import { v } from "better-call";

const greet = v.fn(
  "greet",
  { input: { name: v.string() } },
  async ({ input }) => ({ message: `Hello, ${input.name}` }),
);

await greet({ name: "Ada" });
```

The input validator runs when the function is called. Better Call keeps the declared contract available at runtime for tooling and integrations.
